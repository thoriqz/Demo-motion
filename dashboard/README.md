# Dashboard Divisi Umum (desain liquid glass)

Isi sama dengan dashboard Divisi Umum (menu Ringkasan, Lampiran, Jadwal; 15 laporan;
status per bidang; lampiran berupa tautan, berkas, dan foto), dengan desain
liquid-glass dari `weather/index.html`.

- Latar memakai `../weather/assets/storm-background.jpg` (fallback gradien bila belum ada).
- Logo: `assets/logo_roemantara.png`.
- Data disimpan di localStorage peramban (maks. 1 MB per berkas; foto diperkecil otomatis).
