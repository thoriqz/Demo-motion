# Ikon shortcut ponsel — Dashboard Divisi Umum

Tiga varian berbasis logo Roemantara (putih, hijau, blueprint), masing-masing dalam ukuran
1024, 512, 192 (Android), dan 180 px (iPhone). Pakai file 1024 bila aplikasi meminta gambar sendiri.

- iPhone: aplikasi Pintasan (Shortcuts) → + → Tambah Tindakan "Buka URL" → isi link dashboard →
  ikon bagikan → "Tambahkan ke Layar Utama" → ketuk ikon → "Pilih Foto" → pilih file ikon.
- Android: Chrome → buka link → menu ⋮ → "Tambahkan ke layar utama" memakai ikon claude.ai.
  Untuk ikon Roemantara, gunakan aplikasi pembuat pintasan (mis. "Shortcut Maker"): pilih
  "Situs web/URL", tempel link, lalu ganti ikon dengan file dari folder ini.
